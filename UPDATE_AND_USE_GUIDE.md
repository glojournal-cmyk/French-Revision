# French Revision — Paris Notebook V1

## What is included

- 1,502 source-locked automatically marked questions
- 617 vocabulary / phrase entries, practised in both directions
- 19 controlled 3-sentence and 5-sentence writing tasks
- dated Summer Revision blocks following the reconciled schedule
- longer Quick Notes with Must memorise points
- detailed answer explanations and memory prompts
- focus-first sampling: about 12 focus + 3 cumulative-review questions in a 15-question session
- 85% mastery only after the complete focus pool has been seen
- wrong answers return after 2 days, then 7 days
- sound effects, Pause / Continue, local progress, backup / restore and offline PWA support

## French marking rules

- Missing accents such as é / è / ê / à / ç do not lose the mark in this version.
- The answer screen still displays the source spelling as an accent reminder.
- Base letters, article, gender, plural, adjective agreement, verb ending, tense and negative structure still matter.
- Parenthetical labels are not required: a natural answer such as `under` is accepted for `under (position)`.
- Independent multi-answer questions accept any order and comma, slash, `and`, `et`, semicolon or line-break separators.
- If one item is missing or an extra item is wrong, the feedback names it.
- Full-sentence source translations accept the exact taught model and safe order changes when the same required words and key negative/reflexive structure remain present.
- Writing is not self-marked. The app scores sentence count and each required content / structure job separately, then shows one source-locked model.

## Recommended use

1. Start with **Due today** if it contains questions.
2. Choose the exact dated block.
3. Read Quick Notes for 3–5 minutes and recall the Must memorise items aloud.
4. Complete the 15-question session.
5. Read the explanation after every answer, including correct answers.
6. Repair missed items when they return after 2 days and 7 days.
7. Use **Full Vocabulary Bank** for an extra vocabulary-only session.
8. Use **3–5 Sentence Writing** after the related dated topic.
9. Use Mixed Test only after several dated blocks; use 30 Aug for the 30-question full assessment.

## Update the existing GitHub Pages app

This is a separate French app, so create a separate repository such as `french-revision` the first time.

1. Extract the ZIP on Windows.
2. Upload the files inside this folder to the repository root: `index.html`, `app.js`, `question-bank.js`, `manifest.webmanifest`, `sw.js` and the `icons` folder.
3. Commit the changes.
4. In GitHub **Settings → Pages**, deploy from `main` and `/(root)`.
5. Open the new Pages address in iPad Safari.
6. Safari Share → **Add to Home Screen** → keep **Open as Web App** on → Add.

For later French updates, upload the replacement files to the same repository and commit. Keep the same URL so local progress normally remains available. Export a progress backup before a major update.

## Progress and closing the app

Progress is written to local storage after every answer. Closing the app, Safari or the iPad does not normally erase it. Avoid Private Browsing and do not clear Safari website data. Use **Backup progress** before major updates or device changes.
